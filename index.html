CloudDisk

CloudDisk is a personal tool. It lets its owner use their own Google Drive storage as an extra disk on their own Mac, built on the open-source rclone.

  • It is used only by the owner of this GitHub account, with the owner's own Google accounts.
  • It asks Google only for the drive.file permission, so it can reach only the files it creates itself.
  • It has no server. Everything runs on the owner's computer.
